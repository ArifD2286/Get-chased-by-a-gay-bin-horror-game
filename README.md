# Get chased by a gay bin horror game


screenshot (will be added in future)


With only a short range of sight, be careful of the the monster that lurks around the corners, the gay bin...! Explore the endless maze to find 3 different keys located in different locations, with only little hands you could carry one key at a time. (will be finishing the readme in the future)


### How to play:
- Find the red, green, and blue key that randomly spawn around the map.
  - You can only carry one key at a time so use the key on the escape door whenever you found one.
  - If you pick up another key, the current key on hold would be dropped at where you're standing and there would be a 5 second cooldown between each switch. Keep moving or the monster catches up.
- Once you're caught up by the monster, you would drop the key in your inventory at the location of your death.
- You will have infinite lives and would respawn in a safezone where the monster couldn't enter, with 3 different exits to choose from the monster wouldn't be able to spawn camp you.
